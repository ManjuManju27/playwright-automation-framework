# Playwright Automation Framework

## Project Overview
This project is an enterprise-level Playwright Automation Framework developed for the CDMNext platform to automate functional, regression, smoke, and cross-browser testing.

The framework is designed using scalable automation architecture with reusable components, Page Object Model (POM), and Cucumber BDD integration for maintainability and faster execution.
